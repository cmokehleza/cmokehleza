## About

I build software at **Eclipse Softworks** while studying **Electrical Engineering** in South Africa. Studying hardware and circuits shapes how I write code: understand the constraints first, eliminate unnecessary overhead, and engineer systems that hold up under load.

I care deeply about clean architecture, fast load times, and interfaces that feel intentional rather than templated.
